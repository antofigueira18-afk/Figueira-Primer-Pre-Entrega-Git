# IFPSI - Instituto de Formacion Profesional San Isidro
Proyecto desarrollado para IFPSI, una institución ficticia orientada a la formación y preparación en el ámbito de la actividad física y el entrenamiento, como parte de la práctica de `Git` y `Github` para coderhouse.

## Objetivo
Aprender git y github mientras reforzamos los conocimientos sobre `HTML` y `CSS`, además de ver el desarrollo del proyecto desde algo básico hasta su complejización.

## Tecnologías 
- `HTML`
- `CSS`
- `GIT`

## Flujo de trabajo
Para incorporar nuevas funcionalidades se utiliza un flujo de trabajo con `Git` y `GitHub`:
- Creación de un `Issue` para definir la tarea.
- Creación de una rama para desarrollar la funcionalidad.
- Registro de los cambios mediante `commits`.
- Creación de un `Pull Request` hacia `main`.
- Revisión de los cambios y verificación de conflictos.
- `Merge` del `Pull Request` en `main`.

## Como utilizarlo
Cloná el repositorio y abrí el archivo `index.html`

## Estado del proyecto
Proyecto en desarrollo. Se irán incorporando mejoras y contenidos nuevos a medida que avance el aprendizaje. 
Para la cursada de `git` y `github` el desarrollo de la etapa correspondiente ha finalizado.
